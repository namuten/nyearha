# You Raise Me Up · 플루트·클라리넷 2중주 (초보용) — 설계

날짜: 2026-11-13 · 상태: 승인됨 · 크기: 작은 변경 (대부 구조 복사)

## 의도
- 고등학생 초보 연주자 2명(플루트 1, 클라리넷 1)이 연주할 「You Raise Me Up」 악보·음원 뷰어를 사이트에 추가한다.
- "너무 어렵지 않게" → 초보용. 약 1분 30초.

## 목표 / 비목표 / 실패 조건
- 목표: canon·Godfather와 같은 동작의 악보 뷰어 페이지(총보 + 파트별 PDF·PNG·MP3, 마디 하이라이트).
- 비목표: 원곡 그대로의 재현, 반음 전조, 가사 표기.
- 실패 조건: 초보가 못 읽는 리듬(당김음·붙임줄·16분음표), 클라리넷 브레이크 넘나듦, 임시표 남발.

## 제약
- 저작권: Rolf Løvland 작곡(2002), 저작권 유효. 공개 사이트 게시 위험을 사용자가 알고 그대로 공개하기로 결정 (2026-11-13, 선택지 3).
- 다른 영역 파일은 건드리지 않음 (루트 `index.html`의 `SCORES` 한 줄, CLAUDE.md 섹션 추가만 예외).
- `../` 참조 없이 폴더 내부 상대경로만.

## 접근 방식
| 방식 | 장단점 | 결정 |
|---|---|---|
| A. `Godfather/` 페이지·`source/` 파이프라인 복사 후 곡만 교체 | 글꼴·음색·마디 좌표가 기존과 일치, 수정은 `gen.py`에서 | **채택** |

## 사용자가 정한 것
- 곡: You Raise Me Up, 그대로 공개.
- 편성: 플루트 1, 클라리넷(B♭) 1. 초보용. 약 1분 30초.
- 폴더 이름은 Claude에게 맡김 → `YouRaiseMeUp/`.

## Claude가 정한 것 (승인된 설계)
- 콘서트 B♭장조, 4/4, ♩≈66, 24마디 (≈1분 30초). 전조 없음.
- 구성: 1–2 도입(p) · A(3–10) 1절(mp) · B(11–18) 후렴(mf) · C(19–24) 후렴 뒷부분 클라이맥스(f) → rit., 마지막 늘임표.
- 리듬: 온음표·2분·점2분·4분음표 위주, 8분음표는 선율에 꼭 필요한 곳에만 짝으로. 붙임줄·당김음·임시표 없음.
- 음역: 플루트 F4–B♭5 (콘서트), 클라리넷 기보 E3–G4 (브레이크 아래, 기보 C장조 조표 없음).
- 플루트: 선율 전체. 클라리넷: 도입·A는 온음표·2분음표 화음, B·C는 4분음표가 섞인 쉬운 반주 — 대부처럼 `CHORDS`에서 낮은 화음음을 골라 자동 생성.
- 페이지: 메뉴 합주(총보) → 플루트 → 클라리넷. 파일 `assets/youraisemeup_<id>.pdf|mp3`, `assets/png/youraisemeup_<id>-<쪽>.png`.
- 루트 `index.html` `SCORES`에 한 줄, `CLAUDE.md` 표·섹션 추가.
- 작업 브랜치: `feature/you-raise-me-up` (메인 허브가 아직 `feature/main-hub`에만 있어 그 위에서 분기).

## 빌더에게 맡기는 것
- 선율은 기억으로 입력 → 첫 MP3를 사용자가 듣고 틀린 음을 고친다.
- 원곡 당김음을 4분·8분음표로 단순화하는 구체 방식, 화음 진행 세부.
- `.title-cover` 위치는 대부와 같은 값으로 시작해 첫 쪽 PNG를 보고 확인.

## 변경 (2026-11-13, 첫 빌드 후)
- 사용자 피드백: "임팩트가 없고 이 곡인지도 모르겠다, 클라이맥스만 잘라서".
- 원인: 기억으로 입력한 선율이 원곡과 달랐음. 사용자가 G장조 리드시트(이미지)를 제공.
- 변경: 후렴 8마디만, 원곡 리듬 그대로 B♭로 옮겨 두 번 반복 (1회 mf, 2회 f + 4분음표 반주) + 도입 1마디 + 늘임표. 17마디, 약 71초.
- 리듬 규칙 완화: 8분음표 연속·점4분음표·8분쉼표 허용 (붙임줄·16분음표·임시표·당김음은 여전히 없음). 플루트 음역 A4–C6.
